# 로드맵

아직 하지 않은 개선 아이디어다. 순서는 쓸모가 큰 순이다.

원칙: 카톡 파일(`KakaoTalk.exe`, DLL)은 분석하거나 고치지 않는다. 필요한 정보는 Wine 쪽에서 얻는다. 카톡이 부르는 Windows 함수는 Wine 추적으로 볼 수 있고, 필요하면 riched20처럼 직접 빌드한 Wine DLL로 바꿀 수 있다.

카톡 파일을 직접 분석하지 않는 이유:

- 64비트 클라이언트는 Themida로 보호된 `Vox.dll`에서 죽는다. 32비트 본체도 난독화돼 있을 가능성이 높다.
- 함수 위치나 구조체를 찾아내도 카톡이 업데이트되면 다시 찾아야 한다.
- 카카오 약관은 리버스 엔지니어링을 금지한다.

## 1. 알림을 누르면 그 방 열기

지금은 알림을 누르면 카톡 창만 나온다.

- 방법: 숨겨 둔 카톡 알림 창(`special:katokpopup`)에 Wine 안에서 클릭을 보낸다(창 핸들에 `PostMessage`로 `WM_LBUTTONDOWN`/`WM_LBUTTONUP`). 카톡이 알아서 그 방을 연다.
- 먼저 확인할 것: 알림 창이 몇 초 뒤에 닫히는지. 닫힌 뒤에 알림을 누르면 이 방법은 쓸 수 없고, 채팅 목록에서 방 이름을 찾아 여는 방법을 따로 찾아야 한다.

## 2. 바 아이콘에 안 읽은 메시지 수 표시

- 방법: 카톡이 창 제목이나 작업 표시줄 아이콘을 바꾸는 Win32 호출을 Wine에서 본다. 채팅 목록 맨 위 탭에 그리는 안 읽은 수(`DrawTextExW`)도 이미 글자 추적에 찍힌다.
- relay가 방 이름처럼 숫자 하나만 골라 넘기고, `kakaotalk-tray`가 아이콘에 표시한다.

## 3. Wine 안에 계속 떠 있는 도우미 (붙여넣기 지연 없애기)

붙여넣기 도우미(`setclip.py`, `dropfiles.py`)는 쓸 때마다 Wine에서 Python을 새로 띄워서 1초쯤 걸린다. Wine 안에 도우미 하나를 계속 띄워 두고 요청만 보내면 지연이 줄어든다.

## 하지 않을 것

- 보낸 사람·메시지 내용을 알림에 넣기: 글자 추적으로 가능하지만 원치 않아서 뺐다(방 이름만 보낸다).
- 채팅 DB 복호화, 카톡의 방별 음소거 설정 읽기: 카톡 DLL에서 키 만드는 방식을 찾아야 한다. 분석량이 크고, 약관 문제가 있고, 업데이트마다 깨질 수 있다. 카톡은 알림을 끈 방에 알림 창을 띄우지 않으므로 지금 방식으로도 음소거가 지켜진다.

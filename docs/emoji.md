# 이모지·기호가 네모(☒)로 보이는 문제

카톡 채팅 목록, 말풍선, 방 이름에서 일부 이모지와 기호가 X가 그어진 네모로 보이는 문제다.

## 원인

- 카톡(32비트)은 글자를 GDI+와 riched20으로 그린다. 둘 다 Wine의 GDI 글꼴을 쓴다.
- 이 설정의 기본 글꼴은 Noto Sans CJK KR이다(맑은 고딕 등이 이 글꼴로 대체됨). 이 글꼴에는 ✔ ❤ ⭐ 같은 기호와 이모지, 점자 공백(⠀) 글리프가 없다.
- 없는 글자를 다른 글꼴에서 가져오는 Windows 폰트 링크(SystemLink)가 CJK 글꼴까지만 걸려 있었다.

## 고친 것

- 흑백 이모지 글꼴 Noto Emoji와 Noto Sans Symbols, Noto Sans Symbols 2를 prefix의 Fonts 폴더에 넣는다(`install.sh` 3단계, README 3단계).
- `wine/fontlink.py`가 기존 글꼴들과, 대체 대상인 Noto Sans CJK KR 자체에도 이 글꼴들로 폴백을 건다(폴백은 실제로 쓰인 글꼴 이름으로 찾기 때문).
- 컬러 이모지(Noto Color Emoji)는 Wine의 GDI가 그리지 못해서 흑백 글꼴을 쓴다.

## 확인

Wine 안에서 32비트 테스트 창에 `가 ✔ ⠀ 😀 ★ a`를 GDI(DrawText)로 그려 비교했다.

- 고치기 전: ✔, ⠀ 모두 네모
- 고친 뒤: ✔가 Noto Emoji로, ⠀가 빈칸으로 제대로 그려진다

## 남은 한계

- **😀 👍 🎉 🙏처럼 U+1F000 이상의 이모지**는 여전히 네모 두 개로 보인다. Wine의 GDI 폰트 링크가 UTF-16 서로게이트 쌍을 한 글자로 다루지 않아서, 글꼴 설정만으로는 고칠 수 없다(Wine 쪽 수정이 필요).
- riched20 입력창은 테스트에서 폰트 링크를 쓰지 않았다. 입력 중인 글자의 기호는 여전히 네모일 수 있다.
- 글꼴을 바꾼 뒤에는 카톡을 재시작해야 적용된다.

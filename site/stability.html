안정성

꺼지지 않고, 튀지 않게

카톡이 스스로 종료되는 문제와 타이핑 중 손바닥 탭 문제를 고친 방법, 한글 입력 설정, 새 메시지 알림을 정리했습니다.

크래시

카톡이 스스로 종료되는 문제

채팅 중 카톡이 예고 없이 사라지고, 로그에 다음 줄이 남습니다(종료 코드 3).

  • 원인: Wine의 ITextRange::SetText는 글자를 넣고 줄바꿈을 다시 하지 않습니다. 그 직후 커서를 옮기거나 포커스를 받으면 커서 위치 계산의 assert가 실패해 프로세스가 종료됩니다(WineHQ 40690, 39342).
  • 재현: 32비트 Windows Python으로 RichEdit50W에 SetText → Collapse → Select. 기본 Wine은 매번 종료, 패치본은 통과합니다.
  • 패치: 단정문 대신 밀린 줄바꿈을 먼저 합니다.

Wine RPM을 다시 풀면 기본 riched20.dll이 돌아옵니다. 카톡을 실행할 때마다 함께 실행되는 kakaotalk check가 패치본을 빌드한 Wine 버전과 설치된 버전이 같으면 보관해 둔 패치본을 다시 넣고, 다르면 tools/build-riched20.sh를 다시 실행하라는 경고를 로그에 남깁니다.

Windows 7 원본 msftedit.dll로 바꾸는 방법은 재현 테스트는 통과했지만 카톡이 시작 직후 종료해서 쓸 수 없었습니다. 자세히: docs/riched20-crash.md

트랙패드

타이핑 중 트랙패드 탭 막기

Asahi 트랙패드는 "타이핑 중 비활성화"만으로는 탭이 막히지 않습니다. 탭 클릭을 켜 두면 카톡에서 입력하는 동안 손바닥 탭이 들어옵니다.

  • 카톡 창에 포커스가 있을 때 키가 눌리면 탭 클릭을 끄고, 마지막 입력 0.7초 뒤 다시 켭니다(Hyprland Lua input.keyboard.key).
  • 물리 클릭은 계속 되고, 다른 앱에서는 설정을 바꾸지 않습니다.
  • 사용자의 tap_to_click이 켜져 있을 때만 잠시 끄고, 끝나면 원래 값으로 되돌립니다. 탭 클릭을 끈 채(Omarchy 기본값) 쓰면 설정을 건드리지 않으므로 이 부분을 뺄 필요가 없습니다.

자세히: docs/trackpad-typing.md

한글

한글 입력과 글꼴

On-The-Spot 조합

config/fcitx5/xim.conf

fcitx5 기본값에서는 조합 중인 한글이 아래쪽 별도 네모에 보였다가 늦게 입력됩니다. UseOnTheSpot=True로 입력창 안에 바로 표시합니다.

한글 네모 방지

wine/fontlink.py

입력창 글꼴에 한글이 없으면 네모로 보입니다. 21개 글꼴에 Noto Sans CJK KR SystemLink를 겁니다. 이모지·기호(✔ ❤ ⭐ ⠀)는 흑백 Noto Emoji와 Noto Sans Symbols로 대신 그립니다. 😀 같은 U+1F000 이상 이모지는 Wine 한계로 아직 네모로 보입니다.

데스크톱

바 아이콘과 창 규칙

바 아이콘

bin/kakaotalk-tray

Wine 트레이는 XEmbed 방식이라 Omarchy 바가 표시하지 못합니다. StatusNotifierItem을 직접 등록하고, 클릭하면 숨은 카톡 창을 다시 엽니다. xembedsniproxy는 채팅창 키보드 입력을 가로채서 쓰지 않습니다.

창 규칙

config/hypr/hyprland-kakaotalk.lua

카톡 창을 불투명하게, Wine의 빈 explorer.exe 창은 숨김. 카톡 창에 포커스가 있을 때만 Ctrl+V 파일 드롭과 타이핑 중 탭 막기를 켭니다.

알림

새 메시지 알림

이 환경의 32비트 카톡은 새 메시지 알림 창을 만들지 않습니다. 대신 메시지가 오면 방마다 있는 채팅 기록 DB 파일을 고치므로, 이 변화를 보고 데스크톱 알림을 띄웁니다.

  • kakaotalk-notify가 inotifywait로 chat_data 폴더를 지켜보다가 chatLogs_<방 번호>.edb-wal이 바뀌면 제목 "카카오톡", 본문 "새 메시지"로 알림을 보냅니다. 알림을 누르면 카톡 창이 나옵니다.
  • 메시지 하나에도 쓰기가 여러 번 일어나므로, 한 방에서 5초 안에 이어진 변경은 알림 하나로 묶습니다.
  • 카톡 창에 포커스가 있을 때는 알리지 않습니다. 카톡에서 알림을 끈 방은 설정이 암호화돼 있어 알 수 없으므로, 알림의 "이 방 알림 끄기" 버튼으로 따로 끕니다. 끈 방은 ~/.config/kakaotalk-notify/muted에 남고, 줄을 지우면 다시 켜집니다.
  • 보낸 사람과 방 이름은 보여 주지 않습니다. 파일 이름과 변경 이벤트만 보고, 암호화된 내용은 읽지 않습니다.
  • autostart-kakaotalk.lua로 로그인할 때 자동 시작합니다.

내가 다른 기기에서 보낸 메시지나 읽음 처리·동기화로 DB가 바뀌어도 알림이 뜰 수 있습니다. 자세히: docs/notifications.md

설치

설치 순서

저장소를 받은 폴더에서 install.sh를 실행하거나, 아래 7단계를 차례로 실행합니다. 경로는 모두 홈 디렉터리 기준이고, 시스템 패키지는 설치하지 않습니다.

스크립트

빠른 설치

install.sh가 아래 1~7단계를 차례로 실행합니다. 단계마다 끝난 상태를 먼저 확인해서 이미 끝난 단계는 건너뛰므로, 여러 번 실행해도 됩니다.

바로 아래 준비물을 갖추고, 저장소를 받은 폴더에서 실행합니다.

  • --check는 아무것도 바꾸지 않습니다. 단계마다 [ok], 또는 빠진 것과 함께 [todo]를 한 줄씩 출력합니다. [info] 줄은 설치된 스크립트가 저장소와 다르다는 알림이고 실패가 아닙니다.
  • sudo를 쓰지 않습니다. 필요한 도구가 없으면 목록을 출력하고 멈추므로, 직접 설치한 뒤 다시 실행합니다.
  • ~/.config의 파일은 고치기 전에 <파일>.bak.<시각>으로 백업하고, Hyprland 설정 블록은 한 번만 덧붙입니다.
  • 한 단계만 다시 하려면 ./install.sh --step N(1~7)을 씁니다. 예를 들어 --step 2는 ~/.local/bin의 스크립트를 저장소 버전으로 바꿉니다.

스크립트는 카톡을 실행하지 않습니다. 끝나면 한 번 다시 로그인해 자동 시작 도우미(스크린샷 브리지, 바 아이콘, 알림)를 띄우고, 카톡을 실행해 직접 로그인합니다. 스크립트가 한 단계에서 멈추면 출력을 보고 그 단계를 아래 명령으로 손으로 실행합니다.

설치 전

준비물

  • Apple Silicon 맥 + Asahi Linux(16K 페이지) + Omarchy, Hyprland 0.56 이상(Lua 설정), fcitx5
  • 도구: curl, bsdtar, python3, magick, wl-clipboard, jq, patch, make, gcc, bison, flex, inotifywait(inotify-tools) — 없는 도구는 직접 설치해야 합니다(./install.sh --check가 목록을 알려 줍니다). 카톡과 Wine은 root 없이 사용자 홈에 설치됩니다
  • 디스크: Wine 약 2.3GB, 크래시 패치 빌드 중 임시로 약 1.2GB

단계

단계별 명령

install.sh가 하는 일을 단계별로 적었습니다. 스크립트를 쓰지 않거나 스크립트가 한 단계에서 멈췄을 때 손으로 실행합니다.

  1. 1

    ARM64EC Wine과 FEX DLL 받기

    COPR 저장소 메타데이터(repodata/primary.xml)에서 최신 빌드 경로를 찾습니다. 확인 당시 빌드는 11027010-wine(Wine 11.18-ec3)과 11019142-fex-emu-wine(2609-4)입니다. 시스템에는 설치하지 않습니다.

    Fedora의 alternatives 스크립트가 해 주던 링크를 직접 겁니다. 빠뜨리면 could not exec wineserver나 d3d11.dll not found가 납니다.

    $R/usr/bin/wine64 --version이 wine-11.18 (Staging)을 출력하면 됩니다. 없는 라이브러리는 카메라용 libgphoto2뿐이라 무시해도 됩니다.

  2. 2

    실행 스크립트 설치

    kakaotalk은 HODLL=libwow64fex.dll(32비트 x86 코드를 FEX로 에뮬레이션)과 winebth.sys 차단을 설정합니다. kakaotalk wine <명령>으로 이 prefix의 Wine을 실행할 수 있습니다. kakaotalk check는 로그를 정리하고 필요하면 riched20 패치를 다시 넣습니다. 카톡을 실행할 때마다 자동으로 실행됩니다.

  3. 3

    prefix 생성과 설정 (카톡 설치 전에)

    syswow64가 채워졌는지 확인합니다(파일 800개 이상). 비어 있으면 32비트 설치 파일이 Application could not be started로 실패합니다.

  4. 4

    카카오톡 설치 (32비트 클라이언트)

    C:\Program Files (x86)\Kakao\KakaoTalk\KakaoTalk.exe가 생기면 됩니다. 64비트판은 이 환경에서 동작하지 않습니다.

  5. 5

    클립보드 도우미용 Python

    ARM64 PE라서 Wine에서 에뮬레이션 없이 네이티브로 실행됩니다.

  6. 6

    데스크톱 연동

    ~/.config/omarchy/shell.json의 {"id": "omarchy.tray"} 항목을 config/omarchy/shell-tray-entry.json 내용으로 바꾸고 omarchy restart shell을 실행합니다.

    예전 블록이 이미 들어 있다면 autostart.lua에는 kakaotalk-notify 줄만 추가합니다. 블록을 두 번 덧붙이면 도우미가 두 개씩 뜹니다.

    .desktop의 Exec=kakaotalk은 ~/.local/bin이 세션 PATH에 있다고 가정합니다(Omarchy 기본값).

  7. 7

    입력창 크래시 패치 (riched20)

    기본 Wine의 riched20은 채팅 중 가끔 단정문(MEPF_REWRAP)으로 카톡을 통째로 종료합니다. 패치한 32비트 riched20.dll을 root 없이 교차 빌드해 바꿉니다.

    원본은 보관되며 tools/build-riched20.sh --restore로 되돌립니다. Wine을 같은 버전으로 다시 풀어도 카톡을 실행할 때 kakaotalk check가 패치본을 다시 넣습니다. 자세한 내용은 안정성 페이지에 있습니다.

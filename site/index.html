Omarchy · Asahi Linux · Apple Silicon

Apple Silicon 맥의 Omarchy에서 카카오톡 쓰기

16K 페이지 ARM 리눅스에서 Windows용 카카오톡 32비트 클라이언트를 ARM64EC Wine과 FEX로 네이티브 실행합니다. 한글 입력, 스크린샷·파일 붙여넣기, 바 아이콘까지 맞춘 설정 기록입니다.

결론 요약

무엇이 되고 무엇이 안 되나

x86_64용 가이드(Bottles, Soda)는 ARM 맥에 쓸 수 없습니다. 여러 방식을 시험해 보고 남은 조합은 하나입니다.

방식결과
Bottles + Soda (minpeter 가이드)실패 모두 x86 전용
muvm + FEX + x86 Wine실패 32비트는 로그인 후 흰 창, 64비트는 Themida로 보호된 Vox3.dll에서 크래시
ARM64EC Wine 11.18 + FEX wow64, 32비트 클라이언트동작함 muvm 없이 16K 호스트에서 네이티브 실행
같은 방식 + 64비트 클라이언트실패 Themida로 보호된 Vox.dll에서 실행 위반

카카오톡 바이너리와 계정 정보는 저장소에 들어 있지 않습니다. 설치 파일은 카카오 CDN에서 받습니다. Wine은 시스템에 설치하지 않고 lacamar/wine-arm64ec COPR의 RPM을 풀어서 씁니다.

설치

설치 순서

저장소를 받은 뒤 그 폴더에서 차례로 실행합니다. 경로는 모두 홈 디렉터리 기준입니다.

  1. 1

    ARM64EC Wine과 FEX DLL 받기

    COPR 저장소 메타데이터(repodata/primary.xml)에서 최신 빌드 경로를 찾습니다. 확인 당시 빌드는 11027010-wine(Wine 11.18-ec3)과 11019142-fex-emu-wine(2609-4)입니다. 시스템에는 설치하지 않습니다.

    Fedora의 alternatives 스크립트가 해 주던 링크를 직접 겁니다. 빠뜨리면 could not exec wineserver나 d3d11.dll not found가 납니다.

    $R/usr/bin/wine64 --version이 wine-11.18 (Staging)을 출력하면 됩니다. 없는 라이브러리는 카메라용 libgphoto2뿐이라 무시해도 됩니다.

  2. 2

    실행 스크립트 설치

    kakaotalk은 HODLL=libwow64fex.dll(32비트 x86 코드를 FEX로 에뮬레이션)과 winebth.sys 차단을 설정합니다. kakaotalk wine <명령>으로 이 prefix의 Wine을 실행할 수 있습니다.

  3. 3

    prefix 생성과 설정 (카톡 설치 전에)

    syswow64가 채워졌는지 확인합니다(파일 800개 이상). 비어 있으면 32비트 설치 파일이 Application could not be started로 실패합니다.

  4. 4

    카카오톡 설치 (32비트 클라이언트)

    C:\Program Files (x86)\Kakao\KakaoTalk\KakaoTalk.exe가 생기면 됩니다. 64비트판은 이 환경에서 동작하지 않습니다.

  5. 5

    클립보드 도우미용 Python

    ARM64 PE라서 Wine에서 에뮬레이션 없이 네이티브로 실행됩니다.

  6. 6

    데스크톱 연동

    ~/.config/omarchy/shell.json의 {"id": "omarchy.tray"} 항목을 config/omarchy/shell-tray-entry.json 내용으로 바꾸고 omarchy restart shell을 실행합니다.

    .desktop의 Exec=kakaotalk은 ~/.local/bin이 세션 PATH에 있다고 가정합니다(Omarchy 기본값).

구성 요소

무엇을 맞췄나

Wine 위의 카카오톡을 Omarchy 데스크톱에서 자연스럽게 쓰기 위해 붙인 부분입니다.

한글 입력: On-The-Spot

config/fcitx5/xim.conf

fcitx5 기본값에서는 조합 중인 한글이 아래쪽 별도 네모에 보였다가 늦게 입력됩니다. UseOnTheSpot=True로 입력창 안에 바로 표시합니다.

한글 네모 방지

wine/fontlink.py

입력창 글꼴에 한글이 없으면 네모로 보입니다. 21개 글꼴에 Noto Sans CJK KR SystemLink를 걸어 한글을 대신 그립니다.

스크린샷 붙여넣기

bin/kakaotalk-clipbridge · wine/setclip.py

Wine은 image/png를 Windows 앱이 찾지 않는 형식으로만 넘깁니다. 카톡에 포커스가 있으면 PNG를 BMP로 바꿔 Wine 안의 Windows 클립보드(CF_DIB)에 직접 넣고, 포커스가 빠지면 원래 PNG로 되돌립니다.

스크린샷 붙여넣기 문서

파일·동영상 붙여넣기

bin/kakaotalk-paste · wine/dropfiles.py

카톡의 Ctrl+V는 클립보드에서 파일을 찾지 않아 경로가 글자로 붙습니다. 카톡 창에서만 Ctrl+V를 받아, 복사한 파일을 채팅방에 끌어다 놓기로 넘깁니다. 카톡의 "파일 전송" 확인 창이 뜹니다.

파일 붙여넣기 문서

바 아이콘

bin/kakaotalk-tray

Wine 트레이는 XEmbed 방식이라 Omarchy 바가 표시하지 못합니다. PyGObject로 StatusNotifierItem을 직접 등록하고, 클릭하면 숨은 카톡 창을 다시 엽니다.

창 규칙

config/hypr/hyprland-kakaotalk.lua

카톡 창을 불투명하게 만들고, Wine의 빈 explorer.exe 창을 숨깁니다. 카톡 창에 포커스가 있을 때만 Ctrl+V를 kakaotalk-paste에 연결합니다.

하지 말 것
  • 수 MB 이상의 이미지를 Wayland 클립보드(image/bmp)로 X11 앱에 넘기면 Hyprland의 XWayland 창 관리자가 망가집니다. 모든 X11 창이 사라지고 다시 로그인해야 합니다.
  • X11 CLIPBOARD 소유권을 두고 Hyprland xwm과 경쟁해도 같은 고장이 납니다.
  • 트레이 변환용 xembedsniproxy는 카톡 채팅창의 키보드 입력을 가로챘습니다.

문제 해결

자주 겪는 증상

카톡 창이 안 뜨고 프로세스만 있어요
XWayland 창 관리자가 고장난 상태입니다. 간단한 X11 창도 안 뜨면 확실합니다. omarchy system logout 후 다시 로그인합니다. Xwayland를 종료해도 다시 시작되지 않습니다.
카톡 창이 사라졌어요
트레이로 숨은 것입니다. 바 아이콘을 누르거나 kakaotalk을 다시 실행합니다.
복사한 파일을 붙여넣으면 경로만 들어가요
카톡 창에 포커스가 있을 때 hyprctl binds에 KakaoTalk: paste copied files as attachments가 있는지 확인합니다. 없으면 config/hypr/hyprland-kakaotalk.lua의 Ctrl+V 부분이 hyprland.lua에 들어갔는지, dropfiles.py가 ~/.local/share/kakaotalk-ec/py/에 있는지 봅니다.
로그아웃/로그인 뒤 wireplumber가 CPU 100%예요
wireplumber 0.5.17의 루프 버그입니다. systemctl --user kill --signal=KILL wireplumber && systemctl --user restart wireplumber로 풉니다.
바에 아이콘이 안 보여요
omarchy restart shell을 실행합니다.
pkill -f를 쓰면 셸이 같이 죽어요
패턴이 자기 셸의 명령줄에도 매칭되기 때문입니다. [k]akaotalk처럼 대괄호 형태로 씁니다.

한계와 라이선스

알아 둘 점

  • 64비트 클라이언트는 Themida 때문에 쓸 수 없습니다.
  • 통화와 알림은 충분히 검증하지 않았습니다. 이 환경의 32비트 카톡은 새 메시지 알림 창을 만들지 않았습니다.
  • 바 아이콘에는 안 읽은 메시지 표시가 없습니다.
  • 파일 붙여넣기는 Wine을 한 번 띄우므로 확인 창까지 1~2초 걸립니다.

스크립트와 문서는 MIT 라이선스입니다. 예외로 wine/fontlink.py는 chaotic-ground/kakaotalk-on-wine의 코드를 고친 것이라 GPL-3.0-or-later를 따릅니다. 일부 설정은 minpeter/omarchy-kakaotalk을 참고했습니다.
